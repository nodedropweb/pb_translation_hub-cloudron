## PB Translation Hub

Übersetzungs-Hub für deutsche Beschreibungen von Drupal-Projekten (Module/Themes) von drupal.org.
Synchronisiert Projekt-Metadaten von drupal.org, verwaltet KI-gestützte und manuelle Übersetzungen,
und liefert freigegebene Übersetzungen über eine öffentliche API an das `pb_localizer`-Drupal-Modul aus.
